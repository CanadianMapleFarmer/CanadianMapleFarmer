### About me

Software engineer by day, mostly C#, .NET and Angular. Outside of that, I like building things I’ll actually use. A lot of what’s here started because something annoyed me, I got curious, or I wanted better tools for my own DJ sets.

Away from the keyboard, I’m usually behind the decks playing house and techno with a few mates.

Lately I’ve been messing around with AI coding agents and seeing how far I can push the cheaper models. That rabbit hole turned into Foreman.
